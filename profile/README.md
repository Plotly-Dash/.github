## Common Build Challenges

Slow refreshes often come from heavy calculations inside every callback; cache expensive work before scaling a plotly dash dashboard.  
Deployment issues usually involve environment variables, ports, assets, or package versions; check plotly dash deployment notes before publishing.  
Design drift appears when every page uses different spacing and controls; reuse plotly dash components patterns across the app.
